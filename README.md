# Thai Retail POS

เดสก์ท็อป POS ตัวอย่างสำหรับร้านค้าปลีก พัฒนาด้วย Electron, JavaScript, HTML และ CSS มีฐานข้อมูล JSON ในเครื่อง และรองรับการซิงก์หลายเครื่องผ่าน Wi-Fi ภายในร้าน

> โปรเจกต์นี้จัดทำเป็นผลงานและชุดซอร์สโค้ด ไม่มีไฟล์ติดตั้งหรือข้อมูลร้าน/ลูกค้าจริงรวมอยู่ใน GitHub

## ความสามารถ

- หน้าขายสินค้า ค้นหาด้วยชื่อหรือบาร์โค้ด และเพิ่มรายการกำหนดราคาเอง
- สินค้า รูปสินค้า หมวดหมู่ หน่วยขาย และราคาต้นทุน/ราคาขาย
- ลูกค้าสมาชิก ยอดค้างชำระ และการรับชำระ
- ประวัติบิล แก้ไข ยกเลิก และพิมพ์บิลซ้ำ
- รายงานยอดขายและสำรอง/นำเข้าข้อมูล
- ตั้งค่าข้อมูลร้านและอัปโหลด QR Code สำหรับรับโอนเงิน
- เก็บฐานข้อมูล JSON บนเครื่องหลัก พร้อม API ซิงก์ผ่าน Wi-Fi ภายในร้าน
- แอปเดสก์ท็อป Windows ผ่าน Electron

## เทคโนโลยี

- Electron — แอปเดสก์ท็อป
- HTML, CSS และ JavaScript — หน้าจอ POS
- Node.js HTTP — เซิร์ฟเวอร์และ API ภายในร้าน
- JSON — ฐานข้อมูลไฟล์บนเครื่องหลัก

## เริ่มใช้งานจากซอร์ส

ต้องมี Node.js ติดตั้งบน Windows และเชื่อมต่ออินเทอร์เน็ตระหว่างติดตั้ง dependencies ครั้งแรก

1. เปิด PowerShell ในโฟลเดอร์โปรเจกต์
2. ติดตั้ง dependencies:

   ```powershell
   npm.cmd install
   ```

3. เปิดแอป:

   ```powershell
   npm.cmd start
   ```

4. เมื่อเริ่มใช้งานครั้งแรก เลือก **เครื่องหลัก · เก็บฐานข้อมูล** เพื่อทดลองบนเครื่องเดียว
5. ตั้งชื่อร้านและ PIN ผู้จัดการในเมนู **ตั้งค่า** ก่อนเริ่มใช้จริง

คำสั่ง `npm.cmd` ใช้ได้ใน PowerShell โดยไม่ต้องเปลี่ยนนโยบายการรันสคริปต์

## สร้างตัวติดตั้ง Windows

```powershell
npm.cmd run dist:win
```

ไฟล์ติดตั้งจะถูกสร้างใน `dist/` โฟลเดอร์นี้ถูกละเว้นโดย Git เพื่อไม่ให้ไฟล์ binary ขนาดใหญ่หรือ build ที่ยังไม่สมบูรณ์ถูก commit โดยไม่ตั้งใจ

## โหมดหลายเครื่องผ่าน Wi-Fi

1. เปิดแอปบนเครื่องหลัก แล้วเลือก **เครื่องหลัก · เก็บฐานข้อมูล**
2. ไปที่ **ตั้งค่า → เชื่อมเครื่องอื่นผ่าน Wi-Fi** เพื่อดู IP ของเครื่องหลัก
3. เปิดแอปบนเครื่องลูก เลือก **เครื่องเชื่อมต่อ · ใช้ฐานข้อมูลร่วมกัน** แล้วกรอก IP ดังกล่าว
4. เครื่องทั้งหมดต้องอยู่ในเครือข่าย Wi-Fi เดียวกัน และเครื่องหลักต้องเปิดแอปตลอดเวลาที่ใช้งาน

อย่าเปิดพอร์ตบริการนี้ออกสู่อินเทอร์เน็ตสาธารณะ

## ข้อมูลและความเป็นส่วนตัว

ฐานข้อมูลของแอปไม่ได้อยู่ใน repository โดยเครื่องหลักเก็บไฟล์ข้อมูลใต้โฟลเดอร์ข้อมูลแอปของ Windows (`%APPDATA%\thai-retail-pos\database\pos-data.json`) โฟลเดอร์ `data/`, `dist/` และ `node_modules/` ถูกละเว้นโดย `.gitignore`

ค่าเริ่มต้นในซอร์สเป็นข้อมูลร้านตัวอย่างเท่านั้น ก่อนนำไปใช้จริงให้ตั้งค่าร้านและ PIN ใหม่ และสำรองข้อมูลเป็นประจำ

## โครงสร้างโปรเจกต์

- `main.js`, `preload.js`, `setup.html` — หน้าต่าง Electron และตัวเลือกบทบาทเครื่อง
- `server.js` — HTTP API และการจัดเก็บฐานข้อมูล
- `index.html`, `app.js`, `style.css` — หน้าจอ POS และการทำงานหลัก
- `js/` — โมดูลสินค้า หน่วยขาย ลูกค้า แก้ไขบิล รายงาน และซิงก์
- `package.json` — dependencies และการตั้งค่า build

## สถานะ

โปรเจกต์อยู่ระหว่างพัฒนาและใช้เพื่อสาธิตแนวทางการทำ POS ยังไม่ผ่านการตรวจสอบหรือรับรองว่าเหมาะกับการทำบัญชี/ภาษีอย่างเป็นทางการ ก่อนใช้งานกับข้อมูลจริงควรตรวจสอบขั้นตอนขาย สำรองข้อมูล สิทธิ์ผู้ใช้ และข้อกำหนดทางบัญชีของกิจการ
